# Nebula 网络验证

> **当前版本：2.66.4.13**（版本变更说明随发行处的更新包提供，仓库不再内置 CHANGELOG）

一套基于 PHP + MySQL 的网络验证（授权）系统后端，提供客户端 API 与管理后台 API。
通信协议为 **Nebula 3.1.3**：ECDH P-256 会话握手 + AES-256-GCM 信封 + seq 防重放，客户端零静态对称机密。

官方提供 C++ / Python / C# 三套协议同规格的 SDK和为已有EXE一键加密的客户端（**可在仓库发行处 Releases 下载**），易语言等其他语言依据接口文档直接对接。

## ⚡ 速览

- **环境**：PHP 8.0+ / MySQL 5.7+（建议 8.0），虚拟主机或云服务器均可
- **安装**：见下方「📦 安装」小节（向导式，约 1 分钟完成）
- **客户端对接**：SDK 在仓库发行处（Releases）下载，或按 [docs/API.md](docs/API.md) 手写协议（ECDH 握手 → GCM 信封）
- **管理后台**：浏览器访问安装时生成的后台入口（默认形如 `admin/xxxxxx/`，需携带入口 token），部署后建议改名后台目录

> 界面模板与官网内容运营入口在管理后台「官网运营」，开发规范见 [docs/TEMPLATE.md](docs/TEMPLATE.md)。

## 📦 安装

系统内置一个网页安装向导，**全程图形化，无需手动执行 SQL**。按以下步骤操作即可。

### 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | **8.0+**，且启用 `pdo_mysql`、`openssl`、`json` 扩展（`curl` 用于安装时自动激活授权，建议开启） |
| MySQL | **5.7+**（建议 8.0），需有建库 / 建表权限的数据库账号 |
| Web 服务器 | Apache 或 Nginx，需支持 URL 重写（仓库已带 `.htaccess` / `nginx.conf.example` 规则） |
| 目录权限 | `config/` 目录必须可写（安装时要写入 `config/config.php`） |

> 若 Web 服务器为 Nginx，先参照 `install/nginx.conf.example` 配置重写规则，再启动向导。

### 2. 上传到 Web 根目录

1. 将整个项目（含 `index.php`、`install/`、`admin/`、`config/`、`lib/` 等目录）压缩后上传到 Web 根目录（虚拟主机的 DocumentRoot，或服务器网站目录）。
2. 解压后确认目录结构完整，**建议保持原有目录名不变**（后台入口、`.htaccess` 规则均依赖默认路径）。

### 3. 启动安装向导

浏览器打开安装向导地址：

```
http(s)://你的域名/install/install.php
```

向导为单页多步表单，自动跳过已填项，按 `step` 参数推进。

### 4. 填写安装信息（第一步）

在表单中填写：

- **数据库连接**：地址（默认 `localhost`）、端口、库名、用户名、密码。首次安装可留空由向导创建，或提前建好空库。
- **管理员账号**：默认 `admin`，3–32 位字母 / 数字 / 下划线；**密码** 限可见字符、最长 64 位。
- **后台入口路径**：默认形如 `nbXXXXXX`（安装时随机生成），可自定义（字母开头，3–32 位）。**请牢记**——这是后台访问地址的一部分。
- **授权激活码（选填）**：填入官方授权码可在安装完成时**自动激活**并绑定当前域名。

### 5. 环境自检与建表

点击安装后，向导会：

1. 检查 PHP 版本与 `pdo_mysql` / `openssl` / `json` 扩展是否就绪；
2. 连接数据库，**执行 `install/schema.sql` 创建全部 `nb_` 前缀数据表（共 41 张）**；
3. 写入 `config/config.php`（数据库连接 + 各类配置），并**自动生成后台入口 token**（`admin_entry_key`，访问后台必须携带，防止后台被直接扫描）。

> ⚠️ 全新安装会**删除数据库中全部 `nb_` 前缀表后重建**，所有数据（管理员 / 软件 / 用户 / 卡密 / 订单）将永久丢失。向导会列出受影响的表并要求勾选「我确认要删除」才可继续。

### 6. 自动激活授权（如填了激活码）

安装完成后，系统会通过 `curl` 调用官方授权服务器（`api/license.php`），用填入的激活码绑定当前域名并激活。**激活失败不阻断安装**——系统进入宽限模式，不影响使用，但后续无法在线获取新版本（可到官方门户免费获取试用授权码）。未填激活码则跳过此步。

### 7. 完成并删除 `install` 目录 ⚠️

安装成功页会**显示一次管理员账号信息，请立即复制保存**（之后不再显示）。

**立即手动删除整个 `install/` 目录**——原因：

- 向导内置安全守卫：检测到 `install/install.lock` 即拒绝一切重装提交，防止覆盖 `config.php`、重建管理员；
- 但 `install/` 目录若长期留在线上，仍存在被利用 / 被重装的风险。

删除方式任选其一：

```bash
# 服务器终端（进入项目根目录后）
rm -rf install
```

或直接在文件管理器中删除 `install/` 文件夹。删除后再次访问 `install/install.php` 将返回 404 / 403，表示防护生效。

### 8. 访问管理后台

打开浏览器，访问**安装时设置的后台入口路径**（默认 `nbXXXXXX`），并携带入口 token：

```
http(s)://你的域名/admin/<后台路径>/?entry=<admin_entry_key>
```

`<admin_entry_key>` 即安装时自动生成并写入 `config/config.php` 的 `admin_entry_key`（也可在数据库 `nb_settings` 表的 `skey = 'admin_entry_key'` 查到）。登录后建议到后台「系统设置」修改默认密码、并按需调整后台目录名以增强安全。
